# Library Management System (Система управления библиотекой)

Веб-приложение для автоматизации работы библиотеки: управления книгами, читателями и процессами выдачи/возврата книг. Проект разработан на языке Java с использованием фреймворка Spring Boot.

---

## 🛠 Технологический стек

* **Язык программирования:** Java 21 / 25
* **Фреймворк:** Spring Boot 3.x
  * Spring Web (для создания REST API)
  * Spring Data JPA (для работы с базой данных)
* **Сборщик проекта:** Maven
* **Логирование:** Logback (SLF4J)

---

## 📂 Структура проекта и архитектура

Проект построен по классической многослойной архитектуре (Layered Architecture):

* `controller` — слой обработки HTTP-запросов (REST-контроллеры).
* `service` — слой бизнес-логики приложения.
* `repository` — слой доступа к данным (интерфейсы Spring Data JPA).
* `entity` — доменные модели / сущности базы данных (`Book`, `Reader`, `BookLoan`).
* `dto` — объекты переноса данных (Data Transfer Objects) для безопасного обмена данными между клиентом и сервером.
* `exception` — глобальная обработка ошибок и кастомные исключения.

---

## 🚀 Функционал приложения

* **Управление книгами:** добавление, удаление, просмотр каталога и статуса доступности книг (`LoanStatus`).
* **Управление читателями:** регистрация пользователей библиотеки, просмотр профилей.
* **Учет выдачи книг (`BookLoan`):** фиксация даты выдачи, планируемой даты возврата и отслеживание истории аренды.
* **Валидация данных:** обработка бизнес-ошибок (например, запрет на выдачу уже занятой книги или обработка `ResourceNotFoundException`).
